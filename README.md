## 🛠️ البنية التقنية (Architecture)
- **Framework:** Angular 21 (Modern Standalone Architecture, Zoneless ready).
- **TypeScript:** Strict Typing 100% (بدون استخدام `any` مطلقاً).
- **Reactive State:** Angular Signals (`signal`, `computed`, `effect`) لإدارة السلة والطلبات وحالة الإعلانات.
- **Styling:** Vanilla CSS متقدم وتصميم Responsive متكامل مبني على Design Tokens مستخلصة من ألوان البراند الأصلية.
- **Localization:** Arabic-First RTL بالكامل مع خطوط Google Fonts الفاخرة (`Alexandria` & `Cairo`).
- **Routing:** Angular Router مع Lazy Loading لكافة المسارات.
- **Storage:** LocalStorage لضمان حفظ السلة والطلبات حتى بعد إعادة تحميل الصفحة.

## 🌐 المسارات والصفحات المنفذة (Routes)
1. `/` — الصفحة الرئيسية (Hero، عروض الويك إند، الأقسام، الأكثر طلباً، قصة الفرع، تقييمات، وموقع حياة تاون).
2. `/menu` — المنيو الكامل مع فلاتر الأقسام، ترتيب الأسعار، والبحث المباشر.
3. `/menu/:categorySlug` — استعراض أصناف قسم محدد (مثل: باور فروتيلا، عالم المانجو، الحلويات، الموهيتو...).
4. `/product/:productSlug` — تفاصيل الصنف مع اختيار الأحجام الحقيقية (L، لتر، 4 لتر)، الإضافات (مكسرات، نوتيلا، قشطة، بوبا)، وحقل الملاحظات.
5. `/search` — صفحة نتائج البحث بالاسم أو الوصف أو المكونات.
6. `/cart` — سلة المشتريات التفاعلية مع حساب التوصيل، أكواد الخصم (`FRUITELLA10`، `FRESH15`)، وإدارة الكميات.
7. `/checkout` — إتمام الطلب واختيار الاستلام (توصيل لأحياء العبور أو استلام من فرع حياة تاون)، بيانات العميل، وطرق الدفع (كاش / إنستاباي / فودافون كاش).
8. `/order-confirmation/:orderId` — تأكيد الطلب، رقم الطلب المولد، مشاركة تفاصيل الطلب على واتساب، ورابط التتبع.
9. `/track-order/:orderId` — تتبع مباشر لمراحل تحضير وتوصيل الطلب مع زر محاكاة للتنقل التفاعلي بين المراحل.
10. `/about` — قصة براند فروتيلا، جولة داخل الفرع، ورسالة الجودة.
11. `/contact` — موقع الفرع، أرقام الهاتف للاتصال السريع، رابط واتساب، رابط Google Maps، ونموذج المراسلة.
12. `/privacy` — سياسة الخصوصية وسرية بيانات عملاء العبور.
13. `/terms` — الشروط والأحكام الخاصة بالمرحلة الأولى.
14. `**` — صفحة 404 مخصصة بتصميم فروتيلا مع أزرار للعودة للمنيو.
